Creatorium

A desktop app for people who film a lot and edit a little. Point it at a memory card and it reads every clip, transcribes the talking, describes what's on screen and drafts a script you can actually cut to. None of it leaves your machine.

  • desktop
  • go
  • qt6
  • on-device ai
  • macOS + linux

What happens to a clip

  1. It gets noticed. Watch a folder or a card. ffprobe reads the codec, length and shoot date, and the clip lands in the week it was shot (2026-W42, say).
  2. Keyframes. ffmpeg pulls frames for thumbnails and the scrubber.
  3. Transcription. NVIDIA's Parakeet model runs locally through ONNX Runtime. Every line gets a timestamp and goes into search.
  4. Scene descriptions. A local vision model writes down what's on screen, so “dog runs into the water” turns up even when nobody said it.
  5. A script draft. llama.cpp turns transcripts and scenes into a scene-by-scene script. Every draft is a new version, so nothing gets overwritten.
  6. A cut list. The script becomes an ordered list of clips with suggested in and out points. Drag either end to trim, then export it to your editor: Blender's video sequencer first, others on the list.

Around the app

Built with

Go all the way down, with a Qt6 interface through miqt. SQLite holds the catalogue, transcripts, script versions and an append-only journal of everything the app did, each entry with a link you can paste back in to jump straight to it. Speech runs on ONNX Runtime and drafts run on llama.cpp. Cloud sync exists, but it's optional.

The screenshots here are design mockups for the next version of the interface, filled with made-up footage. The real app is a working Qt6 build that's catching up to them.
